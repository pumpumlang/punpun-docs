# PunPun 1.4.5

PunPun 1.4 closes three source-language gaps while preserving the stable 1.0
language, ABI, package, and lockfile epochs.

## Language

- Functions are values with `fn(T) -> R` types and non-capturing literals.
- `for value in sequence` walks `nums`, `List<T>`, and `Slice<T>`.
- Contracts are value types, including heterogeneous `List<Contract>` values
  and runtime method dispatch.
- The migration dialect remains accepted but reports `W2000` with the modern
  spelling and a pointer to `pp migrate`.

## Tooling and packages

- The PunPun, documentation, and PPX repositories share release `1.4.5`.
- Linux SDK, Linux installer, Arch/CachyOS package, and Windows payload builds
  consume the exact matching PPX tag.
- Normal `pp build`, `pp run`, and `pp check` commands receive materialized PPX
  dependency paths automatically.
- `ppx outdated` reports current and latest package versions and supports JSON
  output for editor integrations.

## Compatibility and limits

Existing 0.6+ source remains supported. Function literals do not capture,
contract dispatch is currently linear at a call site, and sequence iteration
does not yet cover maps or string characters.
